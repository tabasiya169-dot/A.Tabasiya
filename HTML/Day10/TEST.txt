1. What is DOCTYPE?
DOCTYPE tells the browser to use HTML5 standards while rendering the webpage.

2. What is HTML?
HTML stands for HyperText Markup Language and provides the structure of webpages.

3. What is HTML5?
HTML5 is the latest major version of HTML that supports semantic elements, multimedia, and modern web features.

4. What is lang?
The lang attribute specifies the language of the webpage.

5. What is a Meta Tag?
Meta tags are provide information about the webpage for browsers, search engines, and social media platforms.

6. What is UTF-8?
UTF-8 (Unicode Transformation Format - 8-bit) is a character encoding standard that supports almost every language and symbol.

7. What is Open Graph?
Open Graph is a metadata protocol that controls how webpages appear when shared on social media.
