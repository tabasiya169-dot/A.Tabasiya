1. What is block level element?

Ans: A block level element is start with new line and occupies the full width available.

2. Name five block level elements?

Ans: h1
     p

3. What is an Inline element?

Ans: Inline element does not start with a new line and occupies only the required width.

4. Name five Inline elements?

Ans: span
     img
     a
     strong
     em

5. Difference Between Block and Inline elements?

Ans: Block -> New line -> Full width
     Inline -> Same line + Required width.
