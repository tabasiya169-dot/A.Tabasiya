INTERVIEW QUESTIONS:


1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic.

2. What is a variable?

A variable is a named container used to store data or values in a program.

3. What is variable declaration?

Variable declaration means creating a variable using keywords like var, let, or const.

4. What is initialization?

Initialization means assigning an initial value to a variable when it is created.

5. What is an assignment operator?

An assignment operator (=) is used to assign a value to a variable.

Example:
let age = 21;

6. What are var, let and const?

var, let, and const are keywords used the declare variables in JavaScript.
Ex:
var name = "Arun";
let age = 21;
const pi = 3.14;

7. What is the difference between var, let and const?

var can be redeclared and reassigned.
let can be reassigned but cannot be redeclared in the same scope.
const cannot be reassigned or redeclared.

8. What is ES6?

ES6 stands for ECMAScript 2015. It is a major version of JavaScript that introduced features like let, const, arrow functions, classes, and template literals.

9. What is a JavaScript Engine?

A JavaScript Engine is a program that reads, interprets, and executes JavaScript code.

10. What is V8?

V8 is a JavaScript Engine developed by Google. It is used in Google Chrome and Node.js to execute JavaScript code.
